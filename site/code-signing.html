Code signing policy

Last updated 31 October 2026

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

The Mantel installer for Windows (Mantel_x.y.z_x64-setup.exe) and the program it installs, mantel.exe. Only files built from Mantel's own source code are signed. Components from other open source projects that ship inside the installer, such as its NSIS plugins, keep their own signatures or stay unsigned.

Every release is built by GitHub Actions from a version tag in that repository. Nothing built on a personal computer is signed.

Because the certificate belongs to SignPath Foundation, Windows shows SignPath Foundation as the publisher. Releases made before Mantel joined the program are not signed.

What the installer changes

  • It installs Mantel for your Windows account only, in %LOCALAPPDATA%\Mantel, without asking for administrator rights, and adds Mantel's shortcuts and its entry in Installed apps.
  • If your PC lacks the Microsoft Edge WebView2 runtime, it downloads Microsoft's installer for it.
  • If Developer Mode is on, it registers a small app package so that Windows can offer Mantel as the home app of Xbox mode (the full screen experience). It doesn't choose Mantel for you: you pick the home app in Windows Settings.

Uninstalling Mantel removes all of this. Mantel starts with Windows only if you turn that on in its Settings.

Team

An approver checks and approves every signing request by hand. All team accounts on GitHub and SignPath use multi-factor authentication.

Privacy

Mantel has no servers and sends no telemetry. It checks GitHub for new versions of itself, and it reads game details and artwork from Steam and GOG. It reads your Steam and Xbox accounts only after you sign in, and to SteamGridDB only if you add your own key. The privacy statement lists every service Mantel talks to, what it reads and where your data stays.
